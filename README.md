# ARCHIVE 022 (FIXED)

Исправленная версия после технического аудита. Персональный интерактивный подарок на день рождения — цифровой архив с атмосферой загадочного хранилища и уютного скрапбука.

Готовый статический сайт на **HTML5 + CSS3 + Vanilla JavaScript**. Без бэкенда, без фреймворков, без регистрации. Прогресс сохраняется в `localStorage`.

## Структура проекта

```
ARCHIVE-022/
├── index.html      — вся разметка (7 разделов + модальные окна)
├── style.css       — все стили, адаптив, анимации
├── script.js       — игровая логика, загадки, пароль, прогресс
├── assets/
│   ├── images/     — картинки (заглушки, добавляйте свои)
│   ├── icons/      — SVG-иконки (используются inline SVG и CSS)
│   └── fonts/      — локальные шрифты (по умолчанию подключены Google Fonts)
└── README.md
```

## Как запустить

Сайт статический — достаточно открыть файл `index.html` в любом современном браузере:

```
# вариант 1: просто откройте файл
start index.html   (Windows)
open index.html    (macOS)

# вариант 2: локальный сервер (рекомендуется для точной работы анимаций)
python -m http.server 8000
# затем перейдите на http://localhost:8000
```

Или используйте расширение **Live Server** в VS Code.

## Разделы архива

1. **ACCESS** — точка входа, инициализация и первая загадка.
2. **PLAYER** — игровой профиль, загадка "Read the Game", скрытая буква **M**.
3. **CYBER** — цифровой след, загадка "Find the anomaly", скрытая буква **I**.
4. **MIND** — внутренний мир, записки, фрагменты, буква **N**, редактируемая запись.
5. **UNKNOWN** — шесть переворачиваемых карточек, скрытая звезда, буква **D**.
6. **CLASSIFIED** — поле ввода пароля **MIND** (собирается из M·I·N·D).
7. **FINAL LOG** — поздравление с днём рождения, конверт, финальное сообщение.

Прогресс отображается в шапке: `ARCHIVE PROGRESS: X/7`.

## Как менять тексты

Вся пользовательская текстовская контент лежит в **`index.html`**. Найдите соответствующий раздел по `id` (`view-access`, `view-player`, `view-cyber`, `view-mind`, `view-unknown`, `view-classified`, `view-finallog`) и правьте текст внутри.

Заголовки разделов, описания и состояния (`LOCKED`/`AVAILABLE`/`COMPLETED`) задаются в **`script.js`** в объектах `SECTION_LABELS` и `SECTION_DESCS`.

Пароль сегмента CLASSIFIED — константа `PASSWORD = 'MIND'` в начале `script.js`. Буквы M·I·N·D выдаются за нахождение звёзд/фрагментов в разделах PLAYER, CYBER, MIND, UNKNOWN.

## Как добавить изображения

1. Положите файл в `assets/images/` (например, `csgo.jpg`).
2. В `index.html` добавьте ` src="assets/images/csgo.jpg" alt="...">` внутри нужной карточки.
3. Карточки в CSS уже имеют адаптивные размеры; изображения подстраиваются под контейнер.

Для иконок используйте `assets/icons/` и inline `<svg>` (как в декорациях стар), либо подключите файл через `<img src="assets/icons/...">`.

## Публикация

### GitHub Pages
1. Создайте репозиторий на GitHub, например `archive-022`.
2. Загрузите файлы проекта в репозиторий (в корень, без вложенной папки проекта).
3. Перейдите в *Settings → Pages*.
4. В разделе *Build and deployment → Source* выберите ветку `main` (или `master`) и папку `/ (root)`.
5. Нажмите *Save*. Сайт будет доступен по адресу `https://<имя>.github.io/archive-022/`.

### Netlify
1. Зарегистрируйтесь на [netlify.com](https://www.netlify.com).
2. Перетащите папку `ARCHIVE-022` в панель *Sites → Add new site → Deploy manually*.
3. Или подключите репозиторий GitHub для автоматического деплоя при пуше.

Сайт работает на любом статическом хостинге (GitHub Pages, Netlify, Vercel, Яндекс.Облако и др.), так как не требует бэкенда.

## Особенности реализации

- Прогресс, найденные буквы, звёзды и фрагменты хранятся в `localStorage` и восстанавливаются после перезагрузки.
- Кнопка **RESET ARCHIVE** в меню настроек (⚙) сбрасывает прогресс после подтверждения.
- Адаптив под iPhone, планшет и десктоп; учтён `prefers-reduced-motion`.
- Нет внешних зависимостей кроме шрифтов Google Fonts (можно заменить на системные в `style.css`).

## Безопасность

`localStorage` не защищает данные. В проекте нет реальных паролей или конфиденциальных данных — все "секреты" являются частью игровой механики подарка.
